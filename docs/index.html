Bybit Futures Scanner

Runs directly in your iPhone browser using Bybit public market data. No login, API keys, or trades. This is an on-demand scanner, not background monitoring.

Tap Scan now to check connectivity.

Only closed 5-minute candles; liquidity threshold $1m 24h; checks all eligible USDT perpetual contracts (may take several minutes). LONG signals are listed first, then SHORT signals; each side is ranked by confirmation and score. *Entry/stop/target are indicative levels from the last closed 5m candle, recent swing and 14-candle average true range, NOT live executable quotes. Target uses 2 times initial stop distance (1:2 before fees, slippage and funding). Entry check is a screening flag, not a trading instruction. Recheck current bid/ask, spread, contract tick size and order book before placing any order. Stop orders can slip and liquidation may occur before a stop at high leverage. Confirmation requires aligned 5m/15m proxy trends, RSI, volume and 15m price momentum; it is not a guarantee. Early detection uses recent volume buildup with limited price movement; this is not predictive. Trend compares the last closed 5m price against 30m and 45m ago (a proxy, not independent 15m candle confirmation). Liquidity is 24h turnover in USD. EARLY / DEVELOPING / EXTENDED are heuristic labels, not predictions. Score is a relative ranking, not a win probability. No signal is a trade recommendation. Market prices may move before you act. If Bybit blocks browser requests or CORS, the scanner shows an error rather than invented results.
